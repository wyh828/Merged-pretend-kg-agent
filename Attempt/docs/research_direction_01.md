# Research Direction 01

## 已确认的方向

用户本轮明确：领域不设六主题上限，越多越好；热度增长、新技术关联、专利引用增长均为主要目标。先修代码、算法、环境和数据库，再按新结构重新采集。旧数据保留在备份，不作为本次实验输入。历史应覆盖多年；近期和远期信息的贡献可随预测对象变化，进一步研究生命周期阶段与跨事件权重迁移。

## 为什么原来两侧配置没有统一

| 配置与入口 | 实际作用 | 当前限制 |
|---|---|---|
| `techtrend/signal/configs/topics.yaml` → signal DataCollectionAgent | 给六个主题分别定义 OpenAlex/Crossref/arXiv/GitHub/新闻/专利查询词 | 六主题是原信号实验样本，不能代表所有技术领域 |
| `techtrend/config.py` + `.env` → main.py CollectStage | 控制主流水线的源级采集，写入主 `interim` | OpenAlex 默认 AI/CS；arXiv 默认 cs.AI/LG/CL/CV；GitHub 默认 ML/LLM topics；USPTO 默认 G06N |
| `signal/configs/default.yaml` | 信号侧历史区间、时间箱、数据目录、dataset_name | 历史实验为 2023-01 到 2025-07；与主阶段时间配置独立 |
| 主 predict/evaluate/collaborate | 对 works 概念频次及 triples 图谱进行评分与验证 | 读取主题配置指针并不等于六主题采集器已接入主阶段 |

例如，把 topics.yaml 加入 battery_storage，主采集的 G06N / cs.AI 和 GitHub ML 过滤不会自动改变。反过来，主流程扩展量子论文，也不会自动为信号侧增加 quantum 的月度数据。两个入口的查询、主题 ID、采集时间范围、目录、粒度和覆盖统计需要通过统一注册表与转换器衔接；本轮尚未完成该衔接，不能宣称已实现全领域采集。

后续方案：一个可扩展的领域注册表，来源适配器把统一领域映射成不同 API 的类别/查询；允许未分类新技术出现，按领域、来源、月份记录覆盖和配额。六主题保留为历史对照和示例。不能简单清空所有过滤后把全世界一次性下载，也不能用“全领域”名称掩盖实际仍只有 AI 数据。

## 历史跨度、特征窗口与预测范围是三件事

- 历史跨度：例如 2016–2026 的多年事件，不由 horizon=6 限制。正式起止时间取决于首批采集选择和各源覆盖；当前研究数据尚未采集。
- 特征窗口：当前 `forecast_lag=6` 每个训练样本看过去六个月；训练样本可以从多年历史逐月构建。这仍未实现用户要求的长期记忆/不同事件自适应权重。
- 预测范围：`forecast_horizon=6` 指从预测起点往后六个月；`burst_future_months` 控制单次排名/融合的留出范围。不是只下载或只保留六个月历史。
- 回测设置：主 evaluate 的回归 horizon 和排名/TKG 测试跨度有各自配置；结果必须标明每项实际跨度，避免把默认一月的排名回测称为六个月。

本轮已补齐完整日历月。缺月填的是零条已记录活动；缺月累计引用保持上一值。若该月未采集、API 限流或来源缺失，不能据此判断真实活动为零，必须结合覆盖表决定有效回测区间。

## 多年信息与阶段权重迁移：待验证实验

目的：同一对象的旧奠基事件可能仍有价值，最近的重复新闻也未必更重要；跨对象借鉴的是相似发展阶段中的作用规律，而不是直接复制某个具体日期的权重。

建议先做三个可解释基线：全部历史等权、固定时间衰减、按领域和目标单独验证的时间衰减；再加入仅用历史前缀计算的阶段特征，最后验证跨事件迁移。三个预测任务分别选权重和评估，不强迫共享一个系数。

一个候选公式是：归一化贡献 = 时间相关性 × 证据可靠度 × 阶段相似度。公式仅是研究假设，没有被写入生产评分器。近期/前期/后期不能按事后全曲线的峰值或最终寿命来划分；每个预测时点只能使用当时前缀的增速、波动、关联扩散、专利引用轨迹，并允许“无法确定阶段”。当前 S 曲线标签是全史描述性启发式，不能直接当作历史预测的输入或监督真值。

类比案例的“后续结果”也必须在当前预测时点之前已经发生且可获得。对迁移参数做过去区间内的验证，对同一技术家族进行隔离，防止近似复制的论文/实体横跨训练与测试。测试“是否改善”时比较三个目标各自的误差/排序/链接指标，并记录低置信度时退回基础模型的条件。

递归类比须保留证据链与停止条件：限制深度、不重复累计同一证据；先前预测是模型输出，不能被下一层伪装成已发生事实。当前没有启用递归权重算法，不能把设计方向描述为已实现成果。

## 三项目标及交付

| 目标 | 真值与输出 | 主要验证 |
|---|---|---|
| 热度增长 | 按域和来源的历史活动量、份额、增速与排名；附覆盖 | 排名命中、NDCG、Spearman、增长误差；每折候选由过去确定 |
| 新技术关联 | 来源明确的关系候选及置信度；共现与定向语义分开说明 | 时序 MRR/Hits、过去已知实体与冷启动数量、过滤前后规模 |
| 专利引用增长 | 有真实引用事件日期的引用序列、未来增长和误差 | MAE/RMSE/MAPE 与专利年龄分层；禁止按未来总被引选样 |

三个目标都保留，在同一看板分别展示。不能把图 MRR、榜单 NDCG 和回归 RMSE 放在同一尺度上比较高低。原第④目标（生命周期）保留为解释辅助，阶段预测与迁移是否可靠仍需独立实验。
